## 🚀 Como Usar

### Começar Desenvolvimento
```bash
# 1. Setup
cd ritmo-frontend
npm install
echo 'NEXT_PUBLIC_RITMO_API_URL=http://localhost:8000' > .env.local

# 2. Dev
npm run dev

# 3. Ler docs
open docs/README.md
```
